# Captures réelles nécessaires avant publication finale

Priorité haute :

1. Écran principal / tableau de bord.
2. Bottom sheet « Démarrer une séance ».
3. Écran de séance en cours avec une série.
4. Temps de repos actif.
5. Record ou performance précédente visible.
6. Historique mensuel / calendrier.
7. Récapitulatif des muscles travaillés.
8. Objectifs.
9. Carte de partage de séance.

Règles :

- utiliser des données de démonstration non personnelles ;
- masquer toute adresse e-mail, photo ou donnée privée ;
- conserver le même téléphone et le même thème pour une série cohérente ;
- exporter en WebP ou AVIF, avec une version PNG de secours ;
- définir largeur et hauteur dans le HTML ;
- ne pas publier l’illustration fonctionnelle actuelle comme une capture réelle.
